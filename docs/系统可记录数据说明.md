# 系统可记录数据说明

本文档按“实际代码里已经存在的数据结构和导出字段”整理，用于说明这套远程管控系统当前能记录什么数据、这些数据来自哪里、适合用于什么分析。

## 一、记录目标

系统的记录目标不是单一日志留痕，而是建立一条可回放、可量化、可分析的远程操作闭环，覆盖：

1. 操作员发出了什么命令
2. Mac 网关何时接收到命令
3. 命令是否写入 PLC / Modbus
4. PLC / 模拟器给出了什么反馈
5. Vision Pro 何时收到并显示反馈
6. 视频链路在整个过程中是否稳定
7. 当前设备状态和安全状态是否正常

## 二、记录层次

系统当前记录的数据可以分成 6 层。

### 1. 会话层

用于标记一次完整实验或一轮连续管控过程。

典型字段：
- `sessionID`
- `trialID`
- `conditionName`
- `operatorID`
- `notes`
- `mode`

用途：
- 区分不同实验批次
- 对比不同工况、不同操作者、不同网络条件下的性能

### 2. 命令层

用于追踪一次具体控制动作从发出到完成的全过程。

典型字段：
- `commandID`
- `deviceID`
- `action`
- `commandSemantic`
- `startCommandID`
- `stopCommandID`
- `holdDurationMs`

用途：
- 分析每条控制指令是否完成闭环
- 统计启动、停止、点动、参数下发等动作的行为差异

### 3. 反馈层

用于判断 PLC / 模拟器反馈是否符合预期。

典型字段：
- `expectedFeedback`
- `targetFeedbackName`
- `targetFeedbackExpectedValue`
- `targetFeedbackBeforeValue`
- `targetFeedbackCurrentValue`
- `feedbackBefore`
- `actualFeedback`
- `feedbackAfter`
- `feedbackMatched`
- `feedbackWaitDurationMs`

用途：
- 判断控制是否真正生效
- 识别“命令已下发但设备未响应”这类问题

### 4. 视频链路层

用于评估视频在远程监控过程中的可用性。

典型字段：
- `receivedFrameCount`
- `decodedFrameCount`
- `displayedFrameCount`
- `networkMissingFrameCount`
- `decodeDroppedFrameCount`
- `displayDroppedFrameCount`
- `latestEndToEndLatencyMs`
- `stallCount`
- `maxFrameIntervalMs`

用途：
- 评估视频是否适合远程操作
- 定位瓶颈在网络、解码还是显示阶段

### 5. 状态快照层

用于记录事件发生时设备和网关的状态。

典型字段：
- `gatewayStatus`
- `siteStatus`
- `lockState`
- `heartbeatPLC`
- `assemblerRunning`
- `vacuumBoxReady`
- `vacuumFault`
- `pumpFault`

用途：
- 结合命令事件一起判断故障和拦截原因
- 复盘某个时刻系统是否处于可控状态

### 6. 安全与有效性层

用于标识一次控制是否被拦截、是否能作为有效实验样本。

典型字段：
- `blockLayer`
- `blockReason`
- `validSample`
- `invalidReason`
- `unexpectedMotion`

用途：
- 筛除不符合实验要求的数据
- 区分网络问题、控制问题和安全策略拦截

## 四、Vision Pro 端回传的数据

Vision Pro 端除了显示远程画面，也会把视频链路指标按批次回传给网关端。

当前回传内容包括：
- `sessionID`
- 单帧指标数组 `frames`
- `receivedFrameCount`
- `decodedFrameCount`
- `displayedFrameCount`
- `networkMissingFrameCount`
- `decodeDroppedFrameCount`
- `displayDroppedFrameCount`
- `latestEndToEndLatencyMs`
- `clockOffsetMs`
- `clockRoundTripMs`
- `clockSyncValid`
- `stallCount`
- `maxFrameIntervalMs`

其中单帧指标 `VideoReceiverFrameMetric` 包括：
- `sequence`
- `captureTimestamp`
- `encodeStartTimestamp`
- `encodeFinishTimestamp`
- `sendTimestamp`
- `receiveTimestamp`
- `decodeFinishTimestamp`
- `displayTimestamp`
- `endToEndLatencyMs`

这部分数据的价值很高，因为它可以把“主观感觉卡顿”转换成“可量化的链路指标”。

## 六、当前导出方式

当前实现中，Mac 网关端会把监测过程重写为统一 CSV 文件。这个文件适合：

1. Excel / Numbers 直接查看
2. Python / MATLAB 后续统计分析
3. 论文实验表格整理
4. 系统联调问题复盘

如果后续你要继续扩展，我建议下一步可以补两类导出：

1. `JSON` 明细导出  
保留层级结构，更适合程序化分析。

2. `事件 + 帧指标` 分表导出  
一个表记录控制事件，一个表记录单帧视频指标，后处理会更灵活。

## 七、总结

这套系统当前已经具备“工业远程操作实验平台”级别的数据记录能力，覆盖：

- 控制命令闭环
- PLC / 模拟器反馈
- 视频传输质量
- 设备状态快照
- 安全拦截信息
- 试验元数据

也就是说，它不仅能“远程控制”，还已经具备较完整的“实验记录与性能评估”基础。
