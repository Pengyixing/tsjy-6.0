# 管控 6.0

盾构拼装机远程管控系统，包含 `Mac 网关端（tsjy）` 与 `Vision Pro 客户端（tsjy-V）` 两部分。系统面向工业远程操作与监测场景，打通了现场 PLC / Modbus、视频推流、Vision Pro 沉浸式显示、命令回执、试验监测与数据导出。

## 系统组成

### 1. Mac 网关端 `tsjy`
- 采集本地摄像头画面，支持全景候选输入判定
- H.264 编码并通过 WebSocket 分发视频流
- 提供控制 WebSocket 服务，接收 Vision Pro 下发的控制命令
- 提供本地 Modbus TCP Server，等待 PLC 主动连接
- 维护现场设备状态、内容源配置和 Bonjour 服务发现
- 记录试验过程、命令闭环和视频链路指标，并导出 CSV

### 2. Vision Pro 客户端 `tsjy-V`
- 自动发现 Mac 网关或手动连接指定地址
- 接收并解码视频流，显示普通视频、网页和全景内容
- 通过控制通道下发拼装机动作命令与急停
- 在沉浸式空间中展示全景内容，并支持腕部菜单与手部交互
- 将接收、解码、显示阶段的视频指标回传到网关端

## 核心能力

- 工业控制链路：`Vision Pro -> Mac 网关 -> Modbus TCP / 现场接口 -> PLC / 模拟器`
- 视频链路：`摄像头 -> H.264 编码 -> WebSocket -> Vision Pro 解码显示`
- 监测闭环：命令发送、网关接收、寄存器写入、PLC 反馈、Vision Pro 显示反馈全链路可追踪
- 内容管理：支持网页、普通视频、全景照片、全景视频等内容源统一管理
- 数据导出：支持试验过程记录导出，便于实验分析、性能评估和论文/报告整理

## 系统可记录的数据内容

这套系统当前不是只记录“日志文本”，而是能记录一整套实验/操作过程数据。

### 1. 会话与试验元数据
- 会话编号 `sessionID`
- 记录编号 / 试验编号 `trialID`
- 试验工况 `conditionName`
- 动作名称 `actionName`
- 操作者 `operatorID`
- 备注 `notes`
- 试验模式 `mode`
- 重复序号 `repeatIndex`
- 场景编号 `scenarioID`
- 点动周期编号 `jogCycleID`
- 网络工况
- 模拟 PLC 扫描周期
- 人工注入延迟

### 2. 命令生命周期时序数据
- Vision Pro 发送命令时间
- Mac 网关接收命令时间
- 控制校验/验证完成时间
- Modbus 寄存器写入时间
- 模拟器读取时间
- 逻辑处理完成时间
- 反馈写入时间
- Mac 收到 PLC 反馈时间
- Vision Pro 渲染反馈时间
- 命令往返时延
- 控制闭环时间
- 启动响应时间 / 停止响应时间
- 保持时长

### 3. 命令语义与执行结果
- 命令 ID
- 目标设备 ID
- 动作类型，如启动泵、停止泵、前进、后退、旋转、停止、参数下发
- 命令语义标签
- 最终结果
- 失败阶段
- 是否被接受
- 拒绝原因
- 模拟器是否接受
- 模拟器结果码
- 模拟器拒绝原因
- 模拟器执行动作

### 4. PLC / 现场反馈状态
- 预期反馈
- 目标反馈名称
- 目标反馈期望值
- 反馈前值 / 当前值 / 后值
- 实际反馈摘要
- 反馈是否变化
- 反馈是否匹配
- 反馈变化时间
- 反馈等待开始时间
- 反馈匹配时间
- 反馈超时时间
- 反馈等待耗时
- PLC 心跳
- 拼装机运行状态
- 真空到位状态
- 真空故障状态
- 泵站故障状态
- 行走允许 / 油缸允许
- 行走方向 / 回转方向

### 5. 安全与拦截信息
- 控制锁状态
- 拦截层级
- 拦截原因
- 是否有效样本
- 无效原因
- 是否出现非预期动作
- 急停相关事件

### 6. 视频链路质量数据
- 接收帧数
- 解码帧数
- 显示帧数
- 网络缺帧数
- 解码丢帧数
- 显示丢帧数
- 最新网络时延
- 最新解码时延
- 最新显示时延
- 视频端到端时延
- 卡顿次数
- 最大帧间隔
- 时钟偏移
- 时钟往返时间
- 时钟同步是否有效

### 7. 单帧级视频指标
Vision Pro 端会按批次回传单帧指标，字段包括：
- 帧序号 `sequence`
- 采集时间
- 编码开始时间
- 编码完成时间
- 发送时间
- 接收时间
- 解码完成时间
- 显示时间
- 单帧端到端时延

### 8. 视频与流配置数据
- 编码格式 `codec`
- 视频宽高
- 目标帧率
- 目标码率
- NALU 头长度
- 参数集
- 流名称
- 是否关键帧

### 9. 内容源与发布数据
- 内容源 ID、名称、分组、描述、图标
- 内容类型：网页、普通视频、全景照片、全景视频
- 是否启用
- 是否在 Vision Pro 显示
- 默认显示状态
- 排序顺序
- 打开方式 / 显示模式
- 远程 URL / 流地址 / 协议
- 宽高
- 是否允许刷新
- 是否需要认证
- 用户名 / 密码
- 是否通过 Mac 代理
- 是否默认静音
- 本地文件路径
- 媒体相对路径
- MIME 类型
- 最近状态与最近检查时间

### 10. 运行日志与网关状态
- 网关状态
- 现场状态
- 视频通道状态
- 控制通道状态
- 当前连接客户端数量
- 最近视频帧信息
- 运行日志文本
- 设备快照 `GatewaySnapshot`

## 当前导出形式

Mac 网关端支持将试验监测数据导出为统一 CSV 记录表。当前导出的表头已经覆盖：
- 试验元数据
- 全链路时间戳
- 命令反馈匹配结果
- 安全拦截结果
- 视频统计与时延指标
- PLC / 拼装机状态快照
- 详情与备注

更详细的数据项说明见 [docs/系统可记录数据说明.md](./docs/系统可记录数据说明.md)。
